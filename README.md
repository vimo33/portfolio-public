# Vikas Mohan portfolio

Public site: [vikas.followtherabbit.studio](https://vikas.followtherabbit.studio/).

A static portfolio of design, AI-assisted tools and creative exploration. Plain HTML, CSS and JavaScript, with a bundled Three.js runtime. No build step is required.

## Preview

Serve this directory with `python -m http.server 4178 --bind 127.0.0.1`, then open `http://127.0.0.1:4178/`.

## Published experience

`index.html` is the approved pixel-grid version. An opening sequence gathers a small seed and unfolds it into an interwoven structure. The same original procedural material then transforms through eight chapters: the woven structure, a portal, open brackets, an aperture, a branching canopy, woven paths, three connected stages and an open arch. The hero uses code-generated artwork, with no borrowed video or generated portrait scene.

`living-form.js` owns the geometry/material; `pixel-story.js` connects it to scrolling. The project sphere shares the material, clock and sample budget. Opacity transfers only after the page artwork aligns into the gallery camera, where project cards occlude it through a shared depth buffer. Text receives soft clearance and media remains legible. Reduced motion uses completed static poses; Pause artwork freezes motion. Replay formation repeats the opening without reloading the page. Scrolling can continue at any time.

All 22 projects share visible Sphere, Cards and List controls, filters, a complete picker and case pages. Sphere places the globe beside an introduction and selected project explanation: hover previews a card, click brings it forward, and View project opens the case. Full screen keeps the explorer together with an explicit exit and keyboard support; unsupported browsers use a contained fullscreen view. Cards and List keep their respective layouts. Two-axis rotation and selection work while card rotation is paused. Phones default to Cards; reduced-motion and short screens default to List. Longer reading and the interactive example expand deliberately, with accessible close controls.

Day/night and visual-language choices persist between pages. `layout-system.css` supplies consistent screen-sized sections, while `living-colour.css` and `brand-system.css` carry the warm/cool palette. The earlier VM lettering remains in use. The Human Checkpoint card uses a blue surface in day and night modes.

`contact.html` prepares an email draft with a copy fallback. It does not send mail or claim delivery. The checkpoint experiment uses invented data and performs no external action. Form fields are not stored. Google Fonts are optional; the site has system-font fallbacks and no analytics.

The LED Forest preview and short-film video are Vikas's supplied media.

Bakboka groups MPS, Tourism Risk Monitor and Multiplium. Samuha remains active with reduced focus. Rabbit Stack is a planned distribution with working components, not a released installer. Do not invent formal titles, dates or metrics.
